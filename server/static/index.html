    Скачать MP4 (HEVC)

    Записи хранятся в HEVC (H.265) — формат не меняется. Многие браузеры не декодируют HEVC без системного кодека.
    1. Откройте эту страницу в Microsoft Edge или Chrome на Windows.
    2. Установите бесплатно «Расширения для видео HEVC от производителя устройства» из Microsoft Store.
    3. Перезапустите браузер и нажмите ▶ снова.
    4. Либо скачайте файл и откройте в VLC.
